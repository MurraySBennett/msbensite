# Aseprite sources

The editable originals behind `assets/images/button-icons/` and
`assets/images/sprites/`. The exported `.png`/`.gif` in those directories are
byte-identical renders of these files.

Recovered 2026-09-21 from the OSU OneDrive (`personal/pixelArt/files/`) before
that account expired. They existed nowhere else — only the exports were in this
repo, so editing a button meant redrawing it. Keep them here.

`palette-default.ase` and `user.aseprite-brushes` are the palette and brush set
they were drawn with.
